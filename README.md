# NASK Turbo — H5 Bewegen

Snelle oefenapp voor NASK hoofdstuk 5 (bewegingen vastleggen, gemiddelde snelheid, versneld/eenparig/vertraagd, remmen en botsen).

- **Spoedcursus**: 8 vaardigheden, per stuk regel + voorbeeld + valkuil, daarna oefenen tot 3 goed op rij.
- **Turbo-mix**: oneindig veel gegenereerde vragen, met meer nadruk op je zwakke punten.
- **Begrippen**, **Proeftoets** (14 vragen met cijfer en nabespreking), **Spiekbriefje**.

Live: https://tiddeman83.github.io/nask-turbo/ · Ontwikkelen: `npm install && npm run check`, lokaal `npm run serve`.
